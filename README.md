# 仕訳10分ドリル

簿記論の仕訳・金額算定を10分単位で回すための静的Webアプリです。

## 内容

- 仕訳問題と金額算定問題のランダム出題
- 間違い復習キュー
- 弱点カテゴリ表示
- 類題リトライ
- 試験前モード
- お気に入り・メモ保存

## GitHub Pagesで使う

GitHubの `Settings` → `Pages` で、`Deploy from a branch` を選び、`main` / `root` を指定すると公開できます。

公開後のURLは通常こちらです。

https://akito09199509-create.github.io/shiwakeapp/

## 注意

PDF教材やスクリーンショットは含めていません。ブラウザの `localStorage` に学習記録を保存します。
